# AI-assisted development

The solo human builder selected the problem and product direction, supplied the hackathon brief and constraints, funded the disposable testnet identity and requested the implementation and design. Human account authorization, drill enrollment, review and the final presentation remain the builder's responsibility.

OpenAI Codex assisted with official documentation research, comparison of public projects, architecture, Solidity/JavaScript/React implementation, test cases, testnet execution, visual composition and documentation. The wider research workspace contains the evolving plan and sources. An AI-generated visual concept guided art direction; the application scene is original SVG/CSS with real DOM controls.

Validation performed so far: 13 passing Hardhat tests, 10 passing agent tests, successful Vite build, and nine passing live testnet/local-process walkthrough checks in `evidence/live-flow.json`. Local contract tests use explicit precompile mocks; the live walkthrough uses actual QoreChain precompiles. Browser visual verification was partial because the computer-use tool stopped when it could not confidently determine the browser URL.

Known unfinished work is listed in README.md. AI assistance does not establish a security audit, production readiness or official Q-Day Drill survival. Generated work requires continued human review.
